# לוח זמנים — בית הכנסת זוהר מיכל הי"ד

לוח זמני תפילות ושיעורים שבועי, המיועד להדפסה על עמוד A4 יחיד וכן לתצוגה ועריכה בדפדפן.

**הדף החי:** https://tsemachh.github.io/zohar-michal-loach/

בית הכנסת: רח׳ זאב פאלק 18, חומת שמואל, ירושלים · ע"ר 580149748

---

## שימוש שוטף (לגבאי)

1. פותחים את הקישור בדפדפן.
2. לוחצים **"עדכן זמנים לשבוע הקרוב"** — הדף שולף את פרשת השבוע, התאריך העברי וזמני הזריחה, השקיעה והשבת, ומחשב מהם את כל השורות.
3. בודקים את מתג **שעון קיץ / שעון חורף**. הוא נקבע אוטומטית לפי תאריך השבת, וניתן לעקוף בלחיצה.
4. ממלאים את פס **ההודעות** שמעל השורה התחתונה, אם יש.
5. לוחצים **"הדפסה / שמירה כ‑PDF"**. בהגדרות ההדפסה: שוליים "ללא", גרפיקת רקע "מופעל".

**עריכה ידנית:** כל שעה, כותרת ותווית ניתנות לעריכה בלחיצה ישירה. העריכות נשמרות בדפדפן המקומי (localStorage) ונשארות גם אחרי רענון. כפתור **"איפוס עריכות"** מחזיר לברירת המחדל.

**רקע חלופי:** כפתור "בחר תמונת רקע" מחליף את `bg.jpg` בתמונה מהמחשב, לתצוגה מקומית בלבד.

## כללי החישוב

הזמנים לירושלים, לפי שיטת **לוח אור החיים**. הבסיס נשלף מ‑Hebcal בשתי סדרות: רגילה (שקיעה מישורית) ו‑`ue=on` (שקיעה נראית, גבוהה בכ‑4 דקות בירושלים).

**סליחות** — מוצגות רק בעונתן, ונעלמות בשאר השנה:

* **אלול** — מניין הנץ: נץ − 90 דק׳. מניין ב׳: שעה קודם הודו שלו.
* **ג׳–ט׳ בתשרי** — מניין הנץ: נץ − 100 דק׳. מניין ב׳: שעה ו‑10 דק׳ קודם הודו שלו. ראש השנה (א׳–ב׳) ויום כיפור (י׳) מדולגים.
* ההודו במניין הנץ הוא נץ − 20 דק׳, והקרבנות נץ − 30 דק׳. במניין ב׳ ההודו הוא שעת התחלת המניין.
* בשבוע שחוצה את ראש השנה כל יום מקבל את ההיסט שלו והתווית משתנה בהתאם.

**ימי חול** מוצגים כטווח על פני השבוע שאחרי השבת הקרובה (כי הלוח מתפרסם בערב שבת), עם חץ מהיום הראשון לאחרון.

### דיוק מול הלוח

הנוסחאות חולצו מהשוואה ללוח אור החיים בשתי נקודות בשנה (ספטמבר וינואר) ואומתו מול calendar.2net.co.il בסטייה של עד דקה. **פתוח:** צאת השבת בלוח המודפס מופיעה כ‑4 דקות מאוחר יותר (19:37 מול 19:33) — נדרשים נתוני שבת חורפית לכיול.

## מבנה ותחזוקה

```
index.html   — כל הדף: HTML, CSS ו‑JS בקובץ אחד, ללא תלויות
bg.jpg       — תמונת הרקע (מסגרת מעוטרת), 1240×1755
```

* **פריסה:** גיליון של 210×296.9 מ"מ, אזור התוכן ממוקם באחוזים בתוך השטח הבהיר של תמונת הרקע. פונקציית `fit()` מכווצת את התוכן אם הוא חורג, כדי להבטיח עמוד יחיד.
* **הוספת שורה:** הדף מלא כמעט לגמרי. שורה נוספת תגרום לכיווץ אוטומטי קל — עדיף לקצר טקסט או להדק מרווחים (`.sec` ו‑`.row`) במקום.
* **מפתחות localStorage:** `zm_fields_vN` לעריכות, `zm_bg_v1` לרקע, `zm_season_v1` לעונה. שינוי מבני בשורות מחייב העלאת מספר הגרסה, אחרת עריכות ישנות ידרסו את המבנה החדש.
* **דו‑כיווניות:** כל טווח שעות עטוף ב‑`unicode-bidi:isolate`. בלי זה החץ נחשב תו ניטרלי והמספרים מתהפכים ויזואלית בתוך טקסט עברי.
* **תצוגת דסקטופ:** `<meta name="viewport" content="width=820">` — הנייד מציג את הדף המלא במקום פריסה מותאמת.
